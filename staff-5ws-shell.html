How this is counted

Two organisations at one site on one day is a flag, not a finding. It is often legitimate — a counselling session and a child-friendly space in the same shelter reach different people. It becomes double counting only when the same people are counted twice, and only the two organisations can settle that. The same organisation appearing twice under different funding tags is a funding attribution, not duplication, and is shown as such.

How this is counted

One activity, two readings. The worker chose a plain label; the register keeps its code, and this table reads that one code both ways — the IASC intervention pyramid layer, and the 4Ws (2012) subcode the inter-agency return expects. A report filed under the previous list is read through its crosswalk where the match is one-to-one, and is otherwise left as not yet placed rather than assigned by guess. Attendances are sessions: one report is one session with the number of people at it, so a person at two sessions is counted twice.
