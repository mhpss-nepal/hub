# data/

## What belongs here

`demo.js` and `demo.json` — the **synthetic** demonstration dataset, generated by
`../gen.js`. Deterministic: the same seed produces the same dataset on every
machine, so a reviewer sees exactly what the author saw.

`demo.js` assigns `window.DEMO` and is what the pages load. A classic script,
not a module and not a `fetch()`, because both fail when the page is opened
directly from a `file://` URL — and opening the file directly has to work.

## What must never be committed here

- Operational data of any kind, at any stage, in any branch, however briefly
- Partner submissions
- Exports from the reporting workbook
- Any file containing a person's name, telephone number, email address or any
  other detail from which an individual could be identified — service users
  **and staff alike**

`.gitignore` blocks `*.xlsx`, `*.xls`, `*.csv` and `*.json` outside this folder
as a backstop. **A backstop is not a control.** The control is that nobody puts
operational data on a third-party service that has no written agreement covering
it.

If real data is ever needed for a test, generate it — do not borrow it.
