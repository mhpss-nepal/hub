# Current-reader synthetic regression fixtures

`native-wire.json` is the unchanged, explicitly synthetic native joint 0.4 example from the approved native review form. Its venue is `SYNTHETIC community venue`; free-text description and coordination notes are empty and no people or contacts are represented. It is test data, not an operational report, institutional reporter entitlement or evidence of field use.

Provenance: retained from `48-historical-analytics/backend/functions/frozen20/evidence/browser-wire.json`, originally generated by the native form's Synthetic Example action. The real-browser loopback separately generates its reports through that same native action rather than using this file to populate the UI.

The repository intentionally ignores arbitrary JSON operational data. This exact fixture is explicitly tracked; do not broaden the JSON ignore exception. Runtime files under `review-current-v51/` never import or fetch this fixture. Static publication makes tracked test bytes publicly retrievable, so only this synthetic example belongs here.

Checks from the repository root:

```sh
node tests/current-v51/reader.cjs
node tests/current-v51/packaging.cjs
```

The packaging regression exports the committed route and test directory with `git archive` into the configured private `TMPDIR`, then executes the reader suite there. It fails when a fixture is present only in an ignored local working file. It also verifies the synthetic marker and absence of test-fixture imports in committed runtime files. It removes only its own scratch directory.
