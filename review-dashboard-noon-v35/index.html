How this is counted

The denominator is every palika of the districts that appear on the holding-centre roster, narrowed by the place filters and by nothing else — the same rule the roster coverage table follows. Narrowed to one organisation or one activity, a palika with no report from anyone is still a palika with no report. A site's palika comes from the site list; a palika-level report carries its own; a report whose palika is not established is shown as such rather than dropped.

How this is counted

Only sites on the holding-centre roster can appear as uncovered: a site nobody ever listed as a service point cannot be counted as one that was missed. Sites appearing in reports but not on the roster are listed in the second table rather than dropped. How this is counted

Two organisations at one site on one day is a flag, not a finding. It is often legitimate — a counselling session and a child-friendly space in the same shelter reach different people. It becomes double counting only when the same people are counted twice, and only the two organisations can settle that. The same organisation appearing twice under different funding tags is a funding attribution, not duplication, and is shown as such.

How this is counted

One activity, two readings. The worker chose a plain label; the register keeps its code, and this table reads that one code both ways — the IASC intervention pyramid layer, and the 4Ws (2012) subcode the inter-agency return expects. A report filed under the previous list is read through its crosswalk where the match is one-to-one, and is otherwise left as not yet placed rather than assigned by guess. Attendances are sessions: one report is one session with the number of people at it, so a person at two sessions is counted twice.

What the public website is given

The website never reads the register. It reads three documents on a public shelf that a coordinator writes on purpose, from this screen, with the filters above applied.

Demonstration mode, until the review by WHO and the Ministry. Everything this dashboard computes is published as it stands — site level, organisation names, no small-cell suppression — so the full behaviour of the system can be judged. Two things are never published: the free-text description of a report, and any focal-point contact, which never reaches the register at all. After the review, what is public and what is not is decided and the rules are tightened accordingly.
