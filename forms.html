Checking the register…

Service contact

One row per person seen, with the contact code that lets a returning person be recognised without a name being recorded.

Review on the review page →
How this is counted

Distinct people are counted by contact code, which is built on the phone from four identity answers and carries no name. A contact with no code cannot be matched to a returning person, so it is listed as a gap rather than folded in silently. Records that arrived over the network and the same record inside an imported file are one row, matched on the same deterministic identifier both sides compute.

Referral

Who was sent where, and whether the receiving service ever confirmed the person arrived.

Review on the review page →
How this is counted

A referral is complete only when arrival is confirmed, so a high count of unknown arrivals is the measure rather than a data fault: it says the pathway is not closing. Barriers are recorded on the referral itself, which is the only place the reason a person did not arrive is ever written down.

PHQ-9 follow-up

Repeat measures for people already in care, and the item 9 audit.

Review on the review page →
How this is counted

Item 9 is the self-harm item. Every positive answer is listed so that a person can check a referral was recorded for it — that audit is the reason the field exists. A PHQ-9 score is a screening measure and not a diagnosis, and it is read beside the person's own account, never instead of it.

Self-report

What people say about their own situation, anonymously, in their own words.

Review on the review page →
How this is counted

A self-report carries no identity at all, so it can never be matched to a service contact or followed up with an individual. Free text may name someone or describe distress, so it is held for a person to read before it goes anywhere, and it is never published.
