# MHPSS Nepal — Layer 2, the coordination hub

Served at **https://mhpss-nepal.github.io/hub/** (GitHub Pages, branch `main`).

This repository holds the coordination hub and the code every layer of the
system shares:

| Folder | What |
|---|---|
| `index.html`, `coverage.html`, `inbox.html`, `access.html` | the hub pages |
| `assets/` | the shared code — the controlled vocabularies (`codes.js`), the record store and validation (`store.js`), the register bridge (`fb.js`, `fb-config.js`), the design tokens and text setting (`design.css`), the bilingual engine and dictionary (`i18n.js`, `i18n-strings.js`), the mark and icons |
| `data/` | the synthetic demonstration dataset, generated by `gen.js`; nothing in it is response data |
| `docs/DATA_MODEL.md` | the record model and its mapping to the IASC 4Ws |
| `tools/` | the deploy gates: bilingual, text setting, contrast, the rail generator, the DOM sweeps |

The field forms live in the sibling repository **`form`** (served at `/form/`)
and load the shared code from `../hub/assets/`. The public website lives in the
root repository **`mhpss-nepal.github.io`** and reads only what the hub
publishes to `public_stats`.

**No personal data, and none is to be added.** No names, telephone numbers or
email addresses of service users or of staff appear in this repository, in any
branch, however briefly. **No unpublished operational figures.** The synthetic
dataset is labelled synthetic wherever it appears.

Draft instruments, not agreed with EDCD or the MHPSS Technical Working Group.
