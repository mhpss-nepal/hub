Guide alignment, exact exceptions and review scope

GUIDE-ALIGNMENT REVIEW v2 — the 29 September guide documents an observed form, not final institutional authority. Reporting type, retained service setting and delivery mode have separate versioned codes. Hospital opens a dedicated branch, but the exact SORMAS facility directory is unavailable in the scoped sources: only a clearly marked draft facility name is provided. No facility code or directory match is invented; full guide parity is NOT claimed.

Owner-approved extension collects one joint sex × age table for the session and each activity: 0–4, 5–9, 10–17, 18–59, 60+. Female and Male are primary; Other and Not recorded remain distinct advanced declared cells. Wholly blank matrix is unknown, not zero; recorded matrices require every explicit cell and matching own attendance. Girls/Boys <18 and Women/Men ≥18 derive only from these bins. Observed SORMAS input collected separate marginals; no claim it already collects this joint extension. Ward and start time retain their existing optional meanings. BS text is not converted. Old backend compatibility remains held.

Disability controls open only with TG-DIS. Unticking does not erase numeric values or turn asked blank into No: hidden pending answers hold review until the worker reselects or deliberately clears them. Blank asked is not asked. Counts are within attendance; disability definition remains for EDCD.

Description remains the activity descriptor (Word Q22), and activity Other descriptions stay per-row. Separate optional additional or unique coordination notes (Word Q24) have a 220-character maximum. Guide slide 16 restricts notes to programme needs, problems and gaps. Never enter names, phone numbers, personal addresses, clinical or case details. Restricted synthetic emulator storage and reporter-scoped read are connected; programme free text is excluded from Hub CSV. Publishing and production remain disconnected.

Versioned ages remain 0–4 / 5–9 / 10–17 / 18–59 / 60+; independent sex Female / Male / Other, with optional Unknown separately identified. 21 September / 23 September ages 10–19 and 20–59 conflict with the 29 September guide and remain historical, never rebinned. Other is not Unknown. No legacy conversion. Funding source conflict and dynamic rows rather than fixed guide headings remain unresolved.
